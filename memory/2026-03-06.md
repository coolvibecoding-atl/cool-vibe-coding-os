## Audio Engineering Knowledge

### Lessons Learned from Dot Com

**Lesson 1-2:**
- Signal chain: Noise → EQ → Compression → Saturation → Reverb → Stereo → Automation → Bus → Master
- Frequency ranges: Kick 40-100Hz, Bass 60-250Hz, Vocal 200Hz-5kHz
- Panning: vocals/kick/snare = center
- Manny Marroquin style: creative effects, layered reverbs
- Tony Maserati style: smooth midrange, controlled bass

**Lesson 3:**
- Bot training: rule-based reasoning
- Decision trees: IF vocal → center/compress
- File types: WAV 24/48kHz, MP3 avoid EQ boost
- ML features: spectrogram, MFCC, tempo

**Lesson 4:**
- Full AI architecture: 3 layers (Processing, Decision, Evaluation)
- Tech stack: PyTorch, JUCE, Librosa
- Commercial examples: iZotope, LANDR, Sonible
