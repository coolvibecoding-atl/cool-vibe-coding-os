## 🎛️ MIKE DEAN'S MIXING TECHNIQUES

### 1. The "W.A.V.E." Approach
- **W**armth - Analog saturation everywhere
- **A**nalogy - Tape machines, tube gear
- **V**ibe - Feel over perfection
- **E**motion - Capture the moment

### 2. Parallel Compression
- Heavy parallel compression on drums
- Blend aggressive parallel with transparent original
- Creates "glued" sound

### 3. Multiband Processing
- Sub bass: Keep it clean, slight compression
- Low mids: Add warmth/ saturation
- High mids: Control harshness
- Highs: Air band, subtle brightness

### 4. The "Bounced" Sound
- Bounce to tape frequently
- Commit to sounds early
- Work "in the box" but treat like analog
- Don't over-process

### 5. Reference & Levels
- Reference constantly to commercial hits
- A/B between reference and mix
- Match loudness during reference

## 🔥 ACHIEVING THE "KANYE SOUND"

### Characteristics
1. Punchy, authoritative drums
2. Warm, saturated low end
3. Smooth, non-harsh highs
4. Wide stereo field
5. Space and depth
6. Emotional resonance
7. Lo-fi grit meets hi-fi polish

### Techniques

#### Drums
- Layer multiple samples
- Blend live and programmed
- Parallel compress heavily
- Sidechain to bass
- Add subtle distortion

#### Bass
- Sub bass: clean, present
- Mid bass: warm, saturated
- Blend synth and bass guitar
- Slight distortion adds character

#### Vocals
- Compression: slow attack, fast release
- De-ess aggressively
- Add plate reverb
- Automate verse/chorus levels

#### Keys & Synths
- Filter sweeps
- Layer with live instruments
- Add subtle chorus
- Use tape delay
