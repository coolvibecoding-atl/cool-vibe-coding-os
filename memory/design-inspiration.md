# Design Inspiration Resources

## Superdesign (app.superdesign.dev)

AI-powered design tool with prompt library. Key styles to use:

### Popular Design Prompts

1. **High Contrast Landing Page**
   - Swiss-style minimalist
   - Brutalist typography
   - Off-whites, deep blacks, monochromatic grays

2. **Brutalist E-commerce**
   - Massive grotesque typography (Clash Display)
   - Red-orange gradients (#DB4A2B, #F8A348)
   - Warm cream background (#E4E2DD)
   - Scroll-triggered animations

3. **SaaS Landing Page (Developer Tool)**
   - Cream and cobalt palette
   - 12-column grid with 1px borders
   - No rounded corners

4. **Luxury Design System**
   - Dusty rose and charcoal
   - Glassmorphism nav
   - Scroll-triggered reveals
   - Grayscale-to-color image transitions

5. **Lumina SaaS**
   - Neo-Brutalist
   - Bold #ffe17c yellow
   - Cabinet Grotesk + Satoshi fonts
   - Bento grids, marquee animations

6. **Futuristic SaaS**
   - Dark mode hero + light content
   - Glassmorphism
   - Serif-sans pairing

7. **Neo-Brutalist**
   - Neon accents
   - 3D glassmorphism
   - Plus Jakarta Sans

8. **Wellness App**
   - Soft pastels (Coral, Sage, Lavender)
   - Outfit + Reenie Beanie fonts

### Font Recommendations

- Satoshi

## Key Design Principles

### Typography
- Massive headlines (6rem+)
- Tight letter-spacing (-0.02em to -0.04em)
- Editorial layouts

### Colors
- High contrast dark mode
- Neon accents
- Gradient overlays

### Motion
- Scroll-triggered reveals
- Parallax
- Spring physics
- Staggered animations

### Layout
- Bento grids
- Asymmetric layouts
- Generous whitespace
