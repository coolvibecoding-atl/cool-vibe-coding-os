# Audio Mixing - Advanced Techniques

## Lesson 2: Signal Chain & Engineer Styles

---

## The Multi-Objective Goal

**Goal = clarity + emotional impact + balance + translation across speakers**

---

## Core Signal Chain

```
Raw Audio
   ↓
Noise Removal
   ↓
EQ (subtractive first)
   ↓
Compression
   ↓
Saturation / Color
   ↓
Spatial Effects (reverb/delay)
   ↓
Stereo Placement
   ↓
Automation
   ↓
Bus Processing
   ↓
Limiter / Master Bus
```

---

## Bot Mixing Rules

### Key Rules
- **Vocal priority = highest**
- **No frequency masking with vocal**
- If kick and bass overlap <120Hz → sidechain compress bass

### Drums Processing
- Very compressed
- Parallel compression (blend at 20%)
- Bass tightly controlled

### Vocal Processing
- Bright (boost 8kHz)
- Perfectly centered
- Extremely clean

---

## Snare Processing Example

**EQ:**
- +6dB at 200Hz
- +5dB at 5kHz

**Compression:**
- Ratio 6:1
- Fast attack
- Medium release

---

## Lead Vocal Chain

1. Remove noise
2. High-pass at 80Hz
3. Compress (3:1 ratio)
4. De-esser at 6kHz
5. Add plate reverb
6. Automate chorus +2dB

---

## Bus Processing

| Bus | Purpose |
|-----|---------|
| Drum Bus | Process all drums together |
| Parallel Smash Bus | Aggressive parallel compression |
| Vocal Parallel Bus | Vocal glue |
| Reverb Bus | Shared reverb |
| Delay Bus | Shared delay |
| Mix Bus | Master bus processing |

## Engineer Styles

### Manny Marroquin
**Artists:** Kendrick Lamar, Rihanna

**Style:**
- Creative effects
- Layered reverbs
- Stereo depth
- Warm saturation

**Bot Rule:** Chorus section = widen stereo by 10%

---

### Tony Maserati
**Artists:** Beyoncé, Jay-Z

**Style:**
- Smooth midrange
- Controlled bass
- Polished vocals

**Typical Vocal Chain:**
1. EQ
2. Compressor
3. De-esser
4. Saturation
5. Plate Reverb
6. Delay

---

## Low End Rules

- **Vocal = perfectly centered**
- **Mix = extremely clean**
- **Low end = tight but not overpowering**
- **Stereo width = very controlled**
