# SoDoATL MVP Roadmap - March 2026

## Timeline
- **Goal:** Free MVP, polished, ready by end of March 2026
- **Priority:** UI/UX + accessibility for all ages/nationalities

## Key Features (MVP)

### Must Have (Week 1-2)
1. ✅ Enhanced World Cup match schedule (already done)
2. 🏠 Housing shortcuts (Airbnb/VRBO/Booking links)
3. ✈️ Flight shortcuts (Google Flights deep links)
4. 🚗 Car rental shortcuts
5. 🍔 Food by nationality (curated lists by country)
6. 🗺️ Interactive map with layers
7. 🚨 Safety section (crime info, areas to avoid)

### Should Have (Week 2-3)
8. 📍 Live traffic layer
9. 🚌 Transport info (MARTA, rideshare)
10. 🔔 Push notifications
11. 👤 User favorites/saved places

### Nice to Have (Week 3-4)
12. AI Concierge chat
13. Offline maps
14. Multi-language expansion

## Design Principles
- Layer system like WorldView
- Timeline scrubber for tournament dates
- Toggleable layers (food, safety, transport, housing)
- Big buttons, clear typography (accessibility)
- Icon-heavy for non-English speakers
- Dark mode primary

## Technical Approach
- Expo/React Native (existing)
- Free APIs where possible
- Deep links to external services (no payments needed)
- Curated data for MVP (not real-time APIs yet)
