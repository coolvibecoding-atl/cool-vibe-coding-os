# ClawX - Desktop GUI for OpenClaw

## What is ClawX?
**Desktop Interface for OpenClaw AI Agents**

A beautiful desktop GUI that wraps OpenClaw - making AI agent orchestration accessible without using the terminal.

---

## Installed Location
`/Users/coolvibecoding/Desktop/ClawX/`

---

## Features
- Chat interface with AI agents
- Pre-configured model providers
- Multi-language support
- Desktop notifications
- System tray integration

---

## How to Run

### Development Mode
```bash
cd /Users/coolvibecoding/Desktop/ClawX
pnpm run dev
```

### Build for Mac
```bash
pnpm run package:mac
```

### Build for Windows
```bash
pnpm run package:win
```
