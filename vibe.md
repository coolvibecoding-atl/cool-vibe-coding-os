# Cool Vibe Coding — Brand Vibe Guide

## Core Identity
- **Name:** Cool Vibe Coding (CVC)
- **Tagline:** Code Different. Vibe Harder.
- **Tone:** Confident, fresh, urban‑influenced, anti‑generic. Equal parts developer credibility and hip‑hop swagger.
- **Audience:** Builders, indie hackers, AI enthusiasts, creators who care about both craft and culture.

## Voice Principles
- **Direct & Punchy:** No fluff. Get to the point with energy.
- **Culturally Connected:** Use hip‑hop/urban analogies naturally (e.g., “mix that track like a beat”).
- **Inclusive but Real:** Speak to all backgrounds without watering down the vibe.
- **Show, Don’t Just Tell:** Demo‑first mindset. “We built it — here’s exactly how.”

## Content Style

### YouTube Scripts
- **Hook:** “We just built {topic} — here’s exactly how.”
- **Structure:** 0:00 hook → 0:15 intro → problem → solution → demo → insight → CTA → slogan
- **CTA:** Smash that like, subscribe, hit the bell.
- **Length:** 8–12 minutes
- **B‑ROLL:** `[B-ROLL]` tags with `[0:00]` cues
- **Slogan Placement:** Intro and outro

### Twitter Threads
- **Hook tweet:** Bold claim or surprising result
- **Pattern:** Problem → Solution → Tools → Insight → CTA
- **CTA:** “Follow @CoolVibeCoding” + link
- **Hashtags (always):** `#CoolVibeCoding #CodeDifferent #VibeHarder #AgenticAI #BuildInPublic`
- **Style:** 6–8 tweets, max 1–2 lines each

### Newsletter (“The Weekly Vibe”)
- **Header:** “## The Weekly Vibe | Cool Vibe Coding”
- **Sections:** Tool Highlight → Culture x Code → Build Spotlight → Next Week
- **Culture x Code:** Must include hip‑hop/urban analogy for the technical concept
- **Length:** ~300 words, scannable
- **Footer:** Slogan + social links
- **Tone:** Curated friend sending you the best finds

### Short‑Form (TikTok/Reels)
- **Patterns:** “We built {topic} in under an hour”, “POV: You {action} with AI”, “Two devs from Atlanta. Zero limits.”
- **First 3 seconds:** Must grab attention
- **CTA:** Follow in caption
- **Lengths:** 15, 30, 60 sec options

### SEO Metadata
- **Title:** “{topic} — Cool Vibe Coding” or “We Built {topic} (Full Code Inside)”
- **Description:** 150–160 chars, includes slogan, tools, “full code inside”
- **Keywords:** topic, “Cool Vibe Coding”, “AI agent”, “coding tutorial”, “build in public”, “free code”
- **Power words:** wild, dope, broken down, secret, now, free

### Thumbnail Copy
- **Format:** ALL CAPS, 3–5 words, max 30 chars
- **Fonts:** Bebas Neue or Impact
- **Colors:** Trap Red (#FF2D2D) or Terminal Green (#39FF14) on black
- **Options:** “FULL CODE BELOW”, “NO CAP”, “BUILD IN PUBLIC”, “AGENTIC AI”, “LIVE DEMO”

## Design & UX Standards
- **Awwwards‑level, gallery‑worthy, never generic.**
- **Layer‑based interfaces** (like WorldView) for complex apps.
- **Big buttons, clear typography** – accessibility first.
- **Icon‑heavy** for international audiences.
- **Dark mode primary** with neon accents (green/red).
- **Smooth motion** (Framer Motion, GSAP) – nothing stiff.

## Content Rules
- ALWAYS include the slogan in long‑form content.
- ALWAYS use the correct hashtags on social.
- ALWAYS credit tools and inspirations.
- NEVER use filler – every line must earn its place.
- ALWAYS end with a clear CTA (subscribe, follow, check the link).

## Messaging Variations
- **Code Different.** – We do things uniquely.
- **Vibe Harder.** – We go harder, better, fresher.
- **We built {X}.** – Show, don’t tell.
- **Two devs from Atlanta. Zero limits.** – Origin story.
